# Fieldscope

Subcontractor safety compliance for general contractors: OSHA-grounded protocols for
specific tasks, training and review tracking, and PPE checks against daily site photos.
An AI-generated protocol stays a draft until a named person approves it.

**Status:** prototype, pilot scope  
**Code and docs:** [`fieldscope`](https://github.com/justinyurasits/fieldscope) ·
[live demo](https://fieldscope-vm64.onrender.com/)

Its docs still live in the code repository. [#26](https://github.com/justinyurasits/design/issues/26) moves them here, the same as every other project.
